# 📊 Customer Shopping Behavior Data Analysis Project

## 1. Overview

This project focuses on performing end-to-end data analysis to extract meaningful insights from a dataset using Python, PostgreSQL, and Power BI.

The project follows a structured data analytics workflow, starting with dataset loading and Exploratory Data Analysis (EDA), followed by data cleaning, SQL-based analysis, interactive dashboard development, and report creation.

The main objective is to transform raw data into meaningful insights that support better understanding and data-driven decision-making.

## 2. Dataset

The project uses a structured dataset containing relevant information for analysis.

The dataset is initially loaded into Python for exploration and preprocessing. Data quality is improved by identifying and handling missing values, duplicate records, and inconsistencies.

**Dataset Operations:**
- Loading and inspecting the dataset.
- Understanding data structure and data types.
- Identifying missing values and duplicates.
- Cleaning and preprocessing data.
- Preparing the cleaned dataset for further analysis.

## 3. Tools & Technologies

| Tool | Purpose |
|---|---|
| Python | Data loading, EDA, and data cleaning |
| Pandas | Data manipulation and preprocessing |
| NumPy | Numerical operations |
| Matplotlib & Seaborn | Data visualization during EDA |
| PostgreSQL | SQL queries and database analysis |
| Power BI | Interactive dashboard development |
| Jupyter Notebook | Python-based analysis |

## 4. Project Workflow / Steps

### Step 1: Data Loading
- Imported the dataset into Python using Pandas.
- Examined the dataset structure, columns, and dimensions.

### Step 2: Exploratory Data Analysis (EDA)
- Analysed the dataset to understand patterns and distributions.
- Examined statistical summaries.
- Identified trends, relationships, and potential data quality issues.
- Used visualizations to understand the data.

### Step 3: Data Cleaning
- Handled missing and duplicate values.
- Identified and corrected inconsistencies.
- Converted columns into appropriate data types.
- Prepared a clean dataset for analysis.

### Step 4: SQL Analysis using PostgreSQL
- Loaded the cleaned dataset into PostgreSQL.
- Executed SQL queries to retrieve and analyse relevant information.
- Used filtering, sorting, grouping, and aggregate functions.
- Extracted meaningful insights from the database.

### Step 5: Power BI Dashboard
- Connected the analysed dataset to Power BI.
- Created interactive visualizations.
- Used charts, graphs, cards, and filters to present key findings.
- Designed a dashboard to communicate insights effectively.

### Step 6: Report Creation
- Summarized the project workflow and analysis.
- Documented important findings and insights.
- Presented the results in a structured report.

## 5. Dashboard

The Power BI dashboard provides a visual representation of the analysis through interactive charts, graphs, and key performance indicators (KPIs).

**Dashboard Features:**
- Key metrics and performance indicators.
- Interactive charts and visualizations.
- Data comparisons and trend analysis.
- Filters and slicers for exploring data.
- Clear presentation of important insights.
